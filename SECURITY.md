# Security policy

## Reporting a vulnerability

Report security issues privately through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request or discussion for a suspected vulnerability.

Include the affected skill or file, the version or commit, and what an attacker could gain, such as a skill instruction that leads an agent to expose personal data or weaken an auth check.

## Supported versions

identity-skills is released as tagged versions of the plugin. Fixes land on `main` and ship in the next release; only the latest release receives fixes.
